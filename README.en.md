# html_to_ppt

An HTML-to-PowerPoint converter currently tailored to web slides generated by ChatGLM

Images are carried over too: `<img>` tags and CSS `background-image` (data URI, local files and
http(s) URLs) are materialised as pictures in the slides, with `cover` cropping applied to
backgrounds. Slides taller than 16:9 (common with `min-height: 720px` layouts) are scaled down proportionally and centred, so nothing falls outside the page.
